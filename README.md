 AgilePilot - Frontend

A modern, responsive agile project management application built with React, TypeScript, and Tailwind CSS. Streamline sprint planning, smart estimation tools, and real-time analytics for teams seeking efficiency and collaboration.

📋 Features

- Dashboard - Overview of ongoing projects and sprints
- Sprint Planning - Kanban-style task management with drag-and-drop support
- Estimation - Story point estimation and capacity planning (in development)
- Analytics - Sprint progress, burndown charts, and team metrics
- Reports - Generate and export sprint reports
- Team Workload - Monitor team capacity and task distribution
- Dark Mode - Eye-friendly interface with dark theme support
- Real-time Updates - Live task status and progress tracking

 🛠️ Tech Stack

- Frontend Framework: React 18+ with TypeScript
- Styling: Tailwind CSS + Custom CSS
- Charts & Visualization: Recharts
- Icons: Lucide React
- Build Tool: Vite
- Package Manager: npm

 Language Composition
- TypeScript: 96.1%
- CSS: 3.3%
- Other: 0.6%
